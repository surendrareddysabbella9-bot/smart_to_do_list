# 📝 Smart To-Do List

A modern and responsive To-Do List web application built using **HTML**, **CSS**, and **JavaScript**. This application helps users manage daily tasks efficiently with task tracking, completion status, and local storage support.

---

## 🚀 Features

- ✅ Add New Tasks
- ✅ Mark Tasks as Completed
- ✅ Delete Tasks
- ✅ Task Statistics Dashboard
- ✅ Local Storage Support
- ✅ Responsive User Interface
- ✅ Clean and Modern Design

## ⚙️ How It Works

### Add Tasks
Users can enter a task and add it to the list.

### Complete Tasks
Tasks can be marked as completed using the checkbox.

### Delete Tasks
Tasks can be removed from the list with a single click.

### Save Tasks
All tasks are automatically stored using Local Storage, allowing them to remain available even after refreshing the browser.

---

## 📊 Task Statistics

The application automatically tracks:

- Total Tasks
- Completed Tasks
- Remaining Tasks

These statistics update in real time whenever tasks are added, completed, or deleted.
